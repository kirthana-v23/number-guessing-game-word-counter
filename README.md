
# Number Guessing Game & Word Counter

## Project Description
This Python project contains two features:
1. Number Guessing Game
2. Word Counter

## Features
- Random number generation between 1 and 100.
- Maximum of 7 attempts.
- Score starts at 100.
- 10 points deducted for each incorrect guess.
- Tracks the best score.
- Reads text files safely.
- Counts total and unique words.
- Displays the top 10 most common words.

## Technologies Used
- Python
- Random Module
- String Module
- Collections Counter

## How to Run
python main.py
